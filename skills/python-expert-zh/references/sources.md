## 冲突处理与本地综合

- PEP 8 的行宽与 Black/Ruff 默认值可能不同；先沿用项目配置。选择现有格式化器比强制精确行宽更重要，不把 Google 文档与工具默认值混成互斥要求。
- Google 的文档风格可作默认参考，但既有 NumPy 等风格同样可保留。不照搬其专有环境、依赖或历史兼容设置。
- 国内来源提供安全风险参考，并不代表腾讯公布了涵盖全部风格的 Python 企业标准。历史文档中的框架版本和密码策略需按目标版本再核对。
