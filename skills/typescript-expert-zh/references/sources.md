## 冲突处理与本地综合

- Google 的导出、框架和类型细则服务于其工程环境；本 Skill 不把它们全部升级为跨项目禁令。命名和格式默认值是本地选择，既有 formatter 优先。
- 国内来源在此分别提供工程规则与 JS 运行时安全参考，不声称它们发布了完整统一的 TypeScript 公司标准。
- 本文 Promise 归属、取消、资源上限、严格度渐进迁移、金额与协议兼容，是面向通用项目的综合要求。具体 API 由目标运行时和依赖版本决定。
- 不强制替换现有 ESLint 配置，不引入已废弃的 TSLint，也不默认把 `enum`、类、默认导出全部判为错误。
